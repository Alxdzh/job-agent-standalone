运行方式

独立版按你手填的资料和偏好执行；MCP 版由外部 Agent 调用同一套投递工具。服务启动后不会自动投递，必须点击开始或由外部 Agent 明确触发。
“暂停”会停止当前投递轮在当前岗位动作完成后的后续操作；“退出后台”会关闭本次后台服务和浏览器调度。下次请双击快捷方式启动，本版本不设置开机自启计划任务。
静默模式仍使用可见浏览器内核，只把窗口最小化/移出视野；它不一定更低风控。发现验证码或登录失效时，建议切回展示网页。
投递批次
批次后休息（分钟）
岗位之间间隔（秒）
以上三组都必须是“最小值 < 最大值”的范围。持续投递每次开始一个平台批次时，会从“投递批次”范围随机抽取目标数量；批次有成功投递后，再从“批次后休息”范围随机抽取冷却分钟数；每次成功投递后，从“岗位之间间隔”范围随机抽取等待秒数。日志会记录实际抽到的数值；岗位被跳过、没有成功投递或遇到页面/登录问题时，不应把默认最小值误认为随机结果。
调度顺序：一次任务会先检查全部已启用平台；每个平台独立累计成功投递数，达到随机批次数量后进入自己的冷却倒计时。冷却期间会切换到其它已登录且可投递的平台，冷却结束后再回到可投平台队列。窗口仍按平台串行切换，不会同时操作多个网站。
每日允许投递时间
到停止时间后不再开启新岗位；若开始时间晚于停止时间，按跨午夜时间窗处理；两者相同表示全天。

招聘平台登录与启用

四个平台都会显示在这里。打开设置不会自动抢占浏览器；点击“检测四个平台登录状态”才会逐一检查，未登录的平台点击对应“打开登录”。每个平台使用独立的可见 Chrome 用户目录，状态只保存在本机。
