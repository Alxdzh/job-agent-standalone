# 求职管家：脱敏模板包

这是可复制给其他人的通用模板，不包含 API Key、个人资料、简历、投递历史、浏览器登录态或本地 SQLite 数据，也不包含聊天、回复、QQ/微信模块。依赖可以随包提供，配置文件保持空白。

## 两种使用方式

- **独立版**：双击 `one-click-start.bat`。用户在工作台填写自己的云端模型 API、平台登录态、资料和投递偏好，点击“开始本轮”或右上角的“开始持续投递”后，系统按可见网页流程执行。
- **MCP 版**：将 `daemon/mcp-config.example.json` 中的占位路径改成解压后的绝对路径，再导入支持 MCP 的成熟 Agent。外部 Agent 负责规划与讨论，本项目提供四个平台的可见浏览器、资料库、任务状态和投递工具。

两种版本使用同一套工作台、资料库、可见浏览器、任务状态和投递记录。项目不内置聊天 Agent、消息会话、HR 回复、QQ 或微信连接。独立版批量投递需要用户在设置中填写并启用自己的云端模型 API；MCP 版的宿主模型负责规划，但后台 JD 判断仍使用用户在本项目中配置的 API。

## 推荐启动方式（Windows 10/11）

双击根目录的 `one-click-start.bat`。它会按当前 Windows 用户检查并准备 Node.js 22.12+、系统 Chrome、空白配置和桌面快捷方式，然后启动后台服务并打开工作台。依赖已随包提供，不会因为 npm 网络不可用而重复下载。

首次安装 Node.js 或 Chrome 可能需要网络和 Windows 权限确认；脚本只安装公开运行环境，不会填入账号、API Key 或平台登录态。项目使用系统 Chrome，不会把 Puppeteer 下载的 Chromium 当作投递浏览器。离线依赖包不能替代系统 Node.js 和原生 Chrome。

如果电脑没有 `winget`，需要先手动安装 Node.js 22+ 和 Google Chrome，再重新双击启动包。也可以手动在 `daemon` 目录执行 `npm install` 后启动 `node index.mjs`。

## 第一次使用

1. 在“资料”中填写个人信息、经历、方向、城市和求职偏好；在“设置”中填写自己的云端模型 API、平台搜索偏好和运行节奏。
2. 在“设置 → 招聘平台登录与启用”中打开需要的平台可见浏览器并扫码；登录态只保存在当前 Windows 用户目录，换电脑需要重新登录。
3. 确认后点击“开始本轮”执行指定数量，或点击右上角“开始持续投递”执行不限数量的连续任务。
4. 遇到验证码、风控、登录失效或无法确认投递成功时，系统暂停并等待人工处理。

## 运行边界

投递需要明确触发；启动服务、打开工作台、刷新页面和保存配置都不会投递。任务会保存目标、已扫描、已投和剩余数；扫描结束但目标未达到时会标记为未完成，不会假装投完。顶部的“暂停”会保留当前进度，“退出后台”会关闭本次服务；下次请再次双击快捷方式或 `one-click-start.bat`，本版本不设置开机自启计划任务。

工作台默认使用可见原生 Chrome 与持久化用户目录；“静默模式”只改变窗口展示方式，不切换为 headless。城市、关键词、筛选、详情和投递都通过当前页面控件的真实点击、输入和滚轮完成；不能用城市码或查询 URL 代替页面操作。运行节奏是三个范围：批次数量、批次休息分钟数、岗位间隔秒数，每组最小值必须小于最大值。

模板包包含第三方 Node.js 依赖，但不包含任何平台登录态。运行数据写入当前用户目录和 `daemon/state`；招聘平台页面结构、官方接口权限与使用条款可能变化，使用者需要自行确认授权和合规性。
