# Security Policy

## Reporting a problem

Please do not put API keys, cookies, browser profiles, personal resumes, or
database files in a public issue or pull request. Remove the secret from the
local copy and revoke or rotate it first, then report the affected file and a
short, non-sensitive description through a private maintainer channel.

## Local data

The application creates user data, login state, browser profiles, logs, and a
SQLite database on the local machine. These files are intentionally excluded
from version control. Treat them as private credentials and never distribute
them with source code or release archives.

## Responsible use

Use the application only with accounts and websites you are authorized to
operate, and follow the applicable platform rules and local law. The project
does not guarantee that a website will accept automated interaction.
